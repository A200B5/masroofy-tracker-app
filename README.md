# Masroofy Tracker

A personal React project for tracking income, expenses, and monthly budgets.

Live demo: https://masroofy-tracker-app.vercel.app/

## Features
- Income and expense entry, transaction details, editing, and deletion
- Monthly budget tracking and reports
- Arabic and English interfaces with right-to-left layout support
- Dashboard and settings views
- Browser-local storage for saved data

## Data and scope
This is a frontend project, not a bank-connected service. Data is stored in your browser's local storage. It does not sync to a backend or across devices, and clearing local site data removes saved records. Use sample data when exploring the public demo.

## Stack
React, JavaScript, CSS, Vite.

## Run locally
Install Node.js and npm, then run:

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
